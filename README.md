# 🚀 TechNova Solutions - Portal Web Corporativo

Projeto desenvolvido como Avaliação Somativa da Unidade Curricular de Desenvolvimento Front-End, consistindo na criação de um portal institucional completo, responsivo e semântico para a startup **TechNova Solutions** (focada em Computação em Nuvem, Inteligência Artificial e Cibersegurança).

## 🌐 Links do Projeto
* **Repositório Público:** [https://github.com](https://github.com)
* **Portal Publicado (GitHub Pages):** [https://github.io](https://github.io)

## 📁 Estrutura de Pastas
```text
technova-solutions/
├── index.html       # Estrutura semântica em HTML5
├── css/
│   └── style.css    # Estilização e layout responsivo em CSS3
├── img/
│   └── *.webp       # Imagens otimizadas em formato WebP
├── wireframe.png    # Planejamento visual de baixa/média fidelidade
└── README.md        # Documentação e evidências de validação
```

## 🛠️ Tecnologias e Padrões Aplicados
* **HTML5 Semântico:** Uso adequado de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>`, `<table>` acessível e `<footer>`.
* **CSS3:** Estilização moderna, responsividade e animações (Sprint 2).
* **SEO & Acessibilidade (WCAG):** Metadados configurados, hierarquia única de títulos (`<h1>` a `<h4>`), atributos `alt` descritivos e labels vinculados em formulários.
* **Otimização:** Imagens em formato `.webp` e gráficos vetoriais leves.
